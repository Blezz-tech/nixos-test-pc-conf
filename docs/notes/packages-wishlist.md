# Кандидаты в пакеты (не установлены)

Пакеты, которые когда-то пробовались или планировались. Здесь, чтобы они не висели
закомментированными строками в конфиге: комментарий в коде выглядит как «настройка»,
а на деле не делает ничего.

| Пакет | Что это | Откуда взялось |
|-------|---------|----------------|
| `nur.repos.ataraxiasjel.waydroid-script` | скрипт автоматической настройки Waydroid через NUR-репозиторий | был закомментирован в `nixos/packages.nix`, требует подключения входа `nur` во flake |
| `jetbrains.pycharm-community` | IDE PyCharm (бесплатная редакция) | был закомментирован в `nixos/packages.nix` |
| `vopono` | запуск приложений через VPN-неймспейсы (WireGuard/OpenVPN) | был закомментирован в `nixos/packages.nix` |

Как поставить, не меняя конфиг:

```bash
nix shell nixpkgs#vopono -c vopono --help
```

Шаги 15–20 перенесут сюда же кандидатов из `home/programs/packs/` (`games`, `media`,
`dev`, `kde`, `tex`, `office`, `browsers`, `custom`) — там их около 170.
